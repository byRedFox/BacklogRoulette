# My Steam Random

Рандомайзер «Во что сыграть дальше?» для вашей библиотеки Steam.
Программа случайно выбирает игру из списка, показывает обложку, а пройденные игры можно убрать из списка одной кнопкой.

## Возможности

- **Случайный выбор** игры, без повтора одной и той же два раза подряд. Если игра не нравится, нажмите «Другая игра» (или Enter).
- **«Пройдена — убрать»** удаляет игру из списка вместе с обложкой.
- **Импорт из Steam**: подтягивает всю библиотеку или только игры, в которые вы ещё не играли.
- **Обложки скачиваются сами** при первом показе игры: сначала официальная обложка Steam, если её нет — из SteamGridDB. Можно поставить и свою картинку.
- **Ручное добавление**: по одной игре в строке или через `|`, повторы пропускаются.
- Старый список из `SteamGames.xlsx` переносится автоматически при первом запуске.

## Установка

Нужен **Python 3.10+** с Tkinter (стандартный установщик с python.org его включает).

```bat
cd D:\Projects\MySteamRandomApp
pip install -r requirements.txt
python MySteamRandomApp.py
```

### Сборка .exe

Запустите `build.bat`. Он поставит зависимости и PyInstaller, соберёт программу и положит `MySteamRandomApp.exe` в папку проекта.

> `.exe` должен лежать в одной папке с `games.json`, `covers\` и `api_key.txt`: программа ищет данные рядом с собой.

## Ключи и настройки

Ключи в репозиторий не входят: после клонирования введите свои в окне **«Настройки»**, программа сохранит их в `api_key.txt` и `settings.json`.

| Что | Зачем | Где взять |
| --- | --- | --- |
| SteamGridDB API key | Обложки для игр без Steam ID | steamgriddb.com → Preferences → API |
| Steam Web API key | Импорт библиотеки | steamcommunity.com/dev/apikey |
| SteamID64 | Чью библиотеку импортировать | 17 цифр, например через steamid.io |

Для импорта в настройках приватности профиля Steam раздел **«Игровая информация»** должен быть открыт для всех.

## Файлы

| Файл | Что внутри |
| --- | --- |
| `MySteamRandomApp.py` | Программа |
| `games.json` | Список игр (создаётся сам) |
| `covers\` | Обложки, имя файла = название игры |
| `api_key.txt` | Ключ SteamGridDB (не попадает в git) |
| `settings.json` | Ключ Steam Web API и SteamID (не попадает в git) |
| `SteamGames.xlsx` | Старый список; после переноса его можно удалить |
