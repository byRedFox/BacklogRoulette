# Backlog Roulette — как идёт разработка

Файл для продолжения работы в новом чате: что за проект, как мы работаем, какие правила нельзя нарушать, что уже
сделано и на чём остановились. Пользователям — `README.md`, порядок выпуска — `RELEASING.md`.

**Обновлено:** 26.11.2026, после выпуска 2.7.1.

## Проект

- **Backlog Roulette** — «во что сыграть дальше»: рулетка с обложками по библиотеке Steam, портам, дисковым играм,
  эмуляторам и играм Xbox, со страницами игр, заметками, снимками экрана, музыкой и встроенным браузером.
- Автор — Sergey Tsepa ([byRedFox](https://github.com/byRedFox)), лицензия GNU GPL v3.
- Репозиторий: https://github.com/byRedFox/BacklogRoulette
  - ветка `master` — ПК-версия (Python, PySide6 + PySide6-Fluent-Widgets). **exe собирается только из `master`**;
  - ветка `android` — Android-версия (Kotlin, Jetpack Compose).
- Папка проекта на ПК: `D:\Projects\BacklogRoulette` (venv — `.venv`). До 2.0.6 программа называлась My Steam Random.

## Как мы работаем

- Общение — на русском.
- Ассистент правит файлы у себя и отдаёт их целиком. Пользователь копирует их в `D:\Projects\BacklogRoulette`,
  запускает, присылает журнал (`logs\app.log`) и коммитит сам. Ассистент код не запускает — поэтому всё новое
  проверяется у пользователя, а в журнал пишутся подробности для разбора.
- Каждый ответ с изменениями заканчивается тремя частями: **что скопировать**, **что проверить**, **команды git**
  для PowerShell 7 (можно в терминале VS Code), начиная с
  ```powershell
  cd D:\Projects\BacklogRoulette
  .\.venv\Scripts\Activate.ps1
  ```
- В `git add` перечисляются конкретные файлы, перед этим — `git status`.
- Ветки: `git push origin master`, затем `git checkout android`, `git merge master --no-edit`,
  `git push origin android`, `git checkout master`. Слияние — **только `master` → `android`**.
- Релизы — через GitHub CLI (`gh`), по шагам из `RELEASING.md`. Тег и релиз — только после проверки собранного exe.
- Предупреждения `LF will be replaced by CRLF` безобидны. Если файл «изменён», но
  `git diff --ignore-cr-at-eol --stat -- <файл>` пуст — поменялись только окончания строк: `git restore <файл>`.

## Правила безопасности (обязательны всегда)

- «Чем безопаснее, тем лучше»; всё важное — либо с разрешения пользователя, либо с высокой степенью безопасности.
- В git никогда не попадают: `api_key.txt`, `settings.json`, `covers/`, `games.json`, `cache/`, `logs/`, `ports.json`,
  `discs.json`, `emulators.json`, `xbox.json`, `collections.json`, `roulette.json`, `steam_meta.json`, `notes/`,
  `screenshots/`.
- `git push --force` — никогда.
- Логин и пароль Steam программа (и ассистент) не спрашивает и не принимает. Вход — только на сайте Steam.
- Ключи — в `settings.json`, зашифрованы DPAPI. В журнале ключи и токены — `***`, SteamID — последние 4 цифры.
- Запуск игр: только выбранный пользователем файл, без командной строки (shell), со сверкой SHA-256.
- Программа не меняет настройки Windows (и Game Bar, и геймпада).
- Ключ подписи Android — только в GitHub Secrets.
- Обновление программы: только `BacklogRoulette.exe` со страницы релиза этого репозитория, со сверкой SHA-256,
  которую посчитал GitHub. Поэтому файл в релизе всегда называется ровно `BacklogRoulette.exe`, релиз — Latest.
- Сторонние DLL — только свои (пример: SDL2.dll только из своей папки или из пакета, не из PATH).

## Устройство ПК-версии

| Файл | Что внутри |
| --- | --- |
| `MySteamRandomApp.py` | Интерфейс (~18 тыс. строк): окно, страницы, диалоги. `__version__` — здесь |
| `core.py` | Логика без интерфейса (~7,6 тыс. строк): данные, Steam, SteamGridDB, обложки, настройки (`DEFAULT_SETTINGS`), запуск игр, снимки экрана |
| `gamepad_share.py` | Отдельный процесс чтения кнопки Share геймпада Xbox через SDL (с 2.7.1) |
| `MySteamRandomApp.spec` | Сборка PyInstaller (один exe): FFmpeg для трейлеров, CTranslate2/SentencePiece, SDL2.dll → `_sdl2` |
| `build.bat` | Ставит зависимости, рисует значок, собирает `dist\BacklogRoulette.exe` |
| `version_info.txt` | Версия и автор в свойствах exe |
| `requirements.txt` | PySide6, Fluent-Widgets, pillow, requests, ctranslate2, sentencepiece, pysdl2, pysdl2-dll, openpyxl |
| `RELEASING.md` | Порядок выпуска |

Полезное в коде:
- `Worker` — фоновая задача с сигналами `finished`/`failed`; сигналы QObject из Python-потоков Qt сам ставит
  в очередь окна (так сделаны `ImageLoader` и `GamepadRelay`).
- `notify(kind, window, title, text, ms)` — уведомление в стиле программы.
- `Screenshots` (в `MySteamRandomApp.py`) — клавиша снимка и кнопка Share; `PlayTracker` — время в играх,
  вызывает `shots.sync()` при старте и конце игр.
- `NotesDialog` — «Свои заметки», `ShotThumb` — превью снимка, `ShotViewer` — просмотр снимков во весь экран.
- `GriddbCoverDialog` — выбор обложки из SteamGridDB со стрелками; `core.cover_snapshot` / `core.restore_cover`.
- Окно ведёт `logs\app.log` (кнопка «Начать заново» → `app.log.1`), зависания — `logs\hang.log`.

## Уроки, которые стоит помнить

- **Кнопка Share геймпада Xbox (2.7.1).** XInput её не отдаёт. Путь через Xbox Game Bar отпал: у пользователя
  снимки Game Bar выключены. Через SDL:
  - драйвер HIDAPI в SDL на Windows Bluetooth-геймпады Xbox не видит — нужен Raw Input (`SDL_JOYSTICK_RAWINPUT=1`);
  - без видео-подсистемы SDL не разбирает сообщения Windows: нажатия Raw Input (WM_INPUT) приходят в её скрытое окно,
    и их надо забирать самим (`PeekMessage`/`DispatchMessage` в потоке, где вызван `SDL_Init`) — иначе кнопки
    всегда «отпущены»;
  - чтение идёт в отдельном процессе (`gamepad_share.py`; в сборке — `BacklogRoulette.exe --gamepad-share`), процесс
    закрывается вместе с игрой и с программой;
  - у Xbox Series X (PID 0B13) по Bluetooth через Raw Input Share — **кнопка 11** (SDL не называет её MISC1).
- **Зависания со звуком (2.7.1).** Windows шлёт пачку событий при смене устройства — ждём, пока список успокоится,
  и не трогаем проигрыватель, если устройство то же.
- Grep/Glob/PowerShell у ассистента в этом окружении не работают — код ищется чтением файлов по частям.
- При `git merge` без `--no-edit` открывается Vim: Esc, `:wq`, Enter.

## Android-версия (ветка `android`)

- Проект — в папке `android/` (Kotlin + Jetpack Compose, minSdk 26, targetSdk 36), пакет
  `io.github.byredfox.backlogroulette`. Версия — `versionCode`/`versionName` в `android/app/build.gradle.kts`
  (`versionCode` растёт с каждой сборкой).
- Сборка — GitHub Actions (`.github/workflows/android.yml`) при push в `android`, если менялась папка `android/`.
  Подпись — ключом из Secrets `BR_KEYSTORE_BASE64` / `BR_KEYSTORE_PASSWORD`. Результат — артефакт
  `BacklogRoulette-android` (`BacklogRoulette-android.apk` + `SHA256SUMS.txt`).
- Устройство: `MainActivity` → `ui/App.kt` (нижняя панель «Рулетка» / «Игры Steam», боковое меню — `Page`),
  данные — `data/LibraryStore`, журнал — `data/AppLog` (`files/logs/app.log`), тема — `ui/Theme.kt`, обложки — Coil.
- Данные берёт из файла «Экспорт для телефона» ПК-версии (с 2.6.1).
- **0.6.0–0.6.1** — был раздел «Нативные ИИ порты» (каталог портов с GitHub, установка APK со сверкой SHA-256,
  «Играть»). Цепочка установки работала, но сам порт Ship of Harkinian на деле неудобен (долгая распаковка, образ
  не подошёл) — **в 0.6.2 раздел убран целиком**: `Ports.kt`, `PortsScreen.kt`, `port_files.xml`, разрешения
  на установку и удаление приложений, `<queries>` порта и FileProvider. `BacklogApp.removePortLeftovers()` при
  запуске удаляет скачанный APK из `cache/ports` и настройки `ports`. Встроенного браузера на телефоне тоже нет.
- **Сейчас Android-версия** — рулетка по библиотеке Steam и коллекции (данные — из «Экспорта для телефона» ПК).
  Дальше — улучшения именно этого.
- Релизы — общие с ПК (вариант А): `BacklogRoulette.exe` и `BacklogRoulette-android.apk` в одном релизе. Если
  менялась только Android-версия — APK докладывается в текущий Latest-релиз (`gh release upload`, см. `RELEASING.md`).

## На чём остановились и идеи

- **Сейчас:** 2.7.1 выпущена. Android 0.6.2 — порты убраны, приложение снова только Steam-рулетка и коллекции.
- **Если вернёмся к портам:** установка APK со сверкой работала (код — в истории ветки `android`, коммит
  `1ec1431`). Из Android 11+ писать в папки другого приложения нельзя: игру порт должен брать сам. Ship of
  Harkinian (linkzenic) при первом запуске 5–10 минут раскладывает ~7 тыс. файлов в `/sdcard/SOH`.
- **Дальше по портам:** сверить у Ship of Harkinian имя пакета и записать отпечаток подписи автора (`signer`)
  из журнала; затем добавить порты с играми других платформ (кандидаты проверять: APK в релизах GitHub, `digest`,
  как порт получает игру). Sonic Robo Blast 2 (`SRB2-Mobile/SRB2-Android`) не годится — репозиторий в архиве,
  релизов нет. Из Android 11+ писать в папки другого приложения нельзя: игру порт должен брать сам.
